یک ابزار سریع و کاربردی برای استخراج، دانلود و پشتیبان‌گیری از تاریخچه چت‌ها در نسخه وب پیام‌رسان بله (**Bale Messenger**). این برنامه پیام‌ها را با ترتیب کاملاً خطی، مرتب و بدون به‌هم‌ریختگی با نمایش زمان ارسال پیام استخراج کرده و به صورت فایل XMLتحویل می‌دهد. این ابزار از وب اسکریپینگ استفاده می‌کند. در دو نسخه خروجی مدیا و خروجی تکست به تنهایی.

---


## 🛠️ نحوه نصب و اجرا از سورس‌کد
پایتون 3.8 به بالا را نصب کنید و حتما Add to path کرده باشید. مراحل زیر را دنبال کنید:

### 1. نصب پیش‌نیازها
ابتدا کتابخانه‌های مورد نیاز را از طریق فایل `requirements.txt` نصب کنید:
```bash
pip install -r requirements.txt

```

### 2. نحوه استفاده از اسکریپت‌ها

* **قدم اول - شروع استخراج واقعی:**
 فایل اصلی پروژه را اجرا کنید. اگر می‌خواهید مدیا دانلود کنید، نسخه مدیا و اگر فقط متن می‌خواهید، نسخه متنی را اجرا کنید:
```bash
python bale_export_media.py
یا
python bale_export.py

```


مرورگر باز می‌شود. وارد حساب بله خود شوید، چت مورد نظر را باز کنید. توجه داشته باشید که کل تاریخچه چت را خروجی می‌گیرد و اگر از زمان ابتدایی می‌خواهید، از فایل main.py فورک شده از ریپوی اصلی استفاده کنید. یا روی همین فایل‌ها PR بزنید. سپس در ترمینال کلید **Enter** را بزنید تا فرآیند اسکرول اتوماتیک و ذخیره‌سازی شروع شود.
